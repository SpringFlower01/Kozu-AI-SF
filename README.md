# KozuAI — イラスト構図提案・ラフガイド生成アシスタント

イラスト制作における「描き始める前の構図決めに時間がかかる」「限られた作画時間の中で見栄えするアングルが思いつかない」という課題を解決するために開発したWebアプリケーションです。このアプリケーションの最大の目的は、AIとイラスト業界の融合の第一歩となることです。そのためにAIがどのように絵を描く人をサポートすれば、作業を円滑に進め、AIの力に頼りすぎない形で活用できるかを、実際に絵を描く自身の視点を取り入れながら考察し、開発しています。

描きたいイラストの**描画範囲（ショットサイズ）**・**雰囲気**・**シチュエーション**を入力すると、AIが3つの構図プランを提案し、主役の配置・カメラアングル・視線誘導を可視化した**専用ラフ図解（SVG）**を自動生成します。

---

## 主な機能

1. **イラスト制作の実践に即した条件指定UI**
   - **描画範囲（5段階＋自由記述）**: 「顔のみ」「胸より上」「腰より上」「膝より上」「全身」の一般的なショットサイズから選択可能。
   - **雰囲気・テイスト**: 「かわいい」「クール」「エモい」「迫力・バトル」「その他（自由記述）」を選択でき、自由記述が空欄でも条件に応じたシチュエーションを自動補完します。
   - **ワンクリックプリセット**: 具体的な利用シーンをすぐに試せるサンプル依頼を搭載しています。

2. **構造化データによる専用ラフ図解（SVG）の動的描画**
   - AIの回答を単なるテキストで表示するのではなく、構図スタイル・被写体位置・描画範囲・視線誘導方向・演出要素をJSONスキーマとして出力させ、フロントエンド側のJavaScriptでベクター図解（SVG）をリアルタイムに組み立てます。

3. **デュアルモード設計（プレビュー / AI生成モード）**
   - **プレビューモード**: 外部API通信なしで即座に構図提案と図解UIを体験できるデモモードです（公開URL上でも動作します）。
   - **AI生成モード**: バックエンドのFlaskサーバー経由でAIモデルと連携し、任意の条件からオリジナルの構図プランと図解を生成します。

---

## 技術的な工夫

- **AI出力の厳格な型制御（Structured Outputs）**
  Pythonの `Pydantic` と `Literal` 型を用いて、AIが返す構図パラメータの選択肢をシステムレベルで固定しました。これにより、自由記述が短い場合でもパースエラーを防ぎ、安定した図解描画を実現しています。
- **外部APIの障害対策とUX改善**
  アクセス集中による一時的なサーバー混雑（503エラー）に対して、バックエンド側で最大2回の自動リトライ処理を実装しました。また、高度な推論処理に伴う待機時間長期化によるユーザーの不安を軽減するため、目安時間の事前表示と0.1秒単位の経過カウンターを設けています。

## 使用技術

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript, SVG
- **バックエンド**: Python 3, Flask
- **AI / スキーマ検証**: Google GenAI SDK (`gemini-3.8-flash`), Pydantic

## ローカル環境での起動方法（AI生成モードの実行）

公開URL上では「プレビュー」モードが動作します。ローカル環境で「AI生成モード」を動かす場合は以下の手順で起動できます。

1. 必要なライブラリをインストールします。
   ```bash
   pip install -r requirements.txt
   ```
2. 環境変数にAPIキーを設定します（Windows PowerShellの例）。
   ```powershell
   $env:GEMINI_API_KEY="あなたのAPIキー"
   ```
3. アプリケーションを起動し、ブラウザで `http://127.0.0.1:5000` にアクセスします。
   ```bash
   python app.py
   ```
